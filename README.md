# ElPuas Client Studio

Generador estático de reportes mensuales por correo y propuestas comerciales.

## Publicación

Sube la carpeta completa al servidor. No requiere instalación, base de datos ni proceso de compilación. El archivo de entrada es `index.html`.

## Uso

1. Completa el formulario.
2. Revisa la vista previa.
3. Descarga el HTML o cópialo.
4. Para propuestas, usa **Imprimir / PDF** desde el navegador.
5. Cuando el correo indique “reporte adjunto”, agrega manualmente el PDF generado por GoDaddy Hub antes de enviarlo.

Los datos escritos se guardan únicamente en el almacenamiento local del navegador. El logo se carga desde el sitio público de ElPuas Digital Crafts para que también sea visible en correos enviados.
